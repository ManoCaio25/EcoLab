# Assets — EcoLab

Esta versão usa apenas modelos, materiais e animações procedurais escritos para o projeto. Não há arquivos GLB/GLTF, texturas, fontes ou imagens de terceiros no cenário. Os ícones da interface são SVGs definidos no código; a tipografia usa fontes do sistema.

| Elemento | Origem nesta versão | Licença de asset externo |
| --- | --- | --- |
| Quatro edifícios, painéis solares e mobiliário | Geometria procedural em `src/features/eco-sim` | Não se aplica |
| Árvores e canteiros | Geometria procedural com instâncias | Não se aplica |
| Carro e van | Geometria procedural, rodas animadas | Não se aplica |
| Três pedestres | Geometria procedural, caminhada por oscilação dos membros | Não se aplica |
| Canal, água e pontes | Geometria e shader GLSL próprios | Não se aplica |

O código criado permanece sujeito à licença que o proprietário do EcoLab definir. Este documento não atribui uma licença aberta ao projeto.

As tentativas de obter os links de download dos dois pacotes da Kenney retornaram HTTP 403 neste ambiente. Não foram usados espelhos não oficiais. A versão procedural mantém a prova técnica funcional, mas a arte e a caminhada ainda são estilizadas e devem ser refinadas antes de uma entrega visual final.

`models/` e `textures/` estão reservados para futuros assets. Ao incorporar um modelo, incluir aqui a URL exata, autor, licença, alterações e arquivo utilizado; preservar também a licença original junto ao asset.

As licenças das bibliotecas de software são independentes das licenças dos modelos e podem ser consultadas nos respectivos pacotes instalados.
